电视管家

一键全屋关机 · Android 盒子小工具

🎙️ 背景

家里是一条常见链路：腾讯极光 4 Pro 盒子 → Yamaha 功放 → TCL 电视。按下极光遥控电源键，只有盒子自己待机；电视和功放三件套各打各的，得分别按电视遥控和功放遥控。用了很多年，一直都是这个体验。

问题是：电视是国行 TCL，固件对"外来设备"的 CEC standby 一律无视，经过 5 个变体实测全部拒绝；电视上也没有任何可用的多屏网络接口。

直到电视自身的 ADB（必须手动一次开启）被试出来：

adb shell input keyevent KEYCODE_POWER

这台电视会进入整机待机，且重启后 ADB 依旧可用。链路真正打通了。

🔌 架构

遥控器按键 ↓ KEY_POWER 极光盒子 (Android 10) ↓ SCREEN_OFF 广播 ┌─────────────────────────────┐ │ 电视管家（App，前台服务） │ │ · SCREEN_OFF BroadcastReceiver │ │ · 纯 Java ADB 客户端 │ │ · CEC 0F 36 兜底（root 时） │ └─────────────────────────────┘ ├→ TV :5555 input KEYCODE_POWER └→ 电视 → CEC Standby → 功放跟随关机

平时什么都不需要跑，就在盒子上常驻一个前台服务。电视关上时，电视自己会通过 HDMI 发 CEC Standby 广播，Yamaha 功放几乎百分百跟随关机。

✨ 能力

  • SCREEN_OFF 双路触发：广播监听 + 每 1.5s 轮询 dumpsys power
  • 纯 Java ADB 客户端：内置 ADB 协议（CNXN/OPEN/OKAY/WRTE/CLSE、AOSP 字节求和校验），不依赖 adb 二进制
  • 自动发现电视：扫描同网段 5555 的 ADB 设备，读 ro.product.model 写入配置；换电视也能用
  • 手动按钮：关电视+关功放、测试关电视、启动/停止常驻
  • 开机自启（BOOT_COMPLETED / QUICKBOOT幂等处理）
  • 暗色卡片化 UI，适配电视遥控键导航，带焦点高亮（白/蓝描边）
  • CEC 兜底：有 root 时可直接 echo 0F 36 > /sys/class/cec/cmd 关功放

🔐 关键协议细节

  • ADB 协议 data_check = AOSP 字节求和（calculate_apacket_checksum），不是 CRC32/adler32
  • shell 字符串末尾必须带 NUL，否则电视静默不回包
  • CNXN 的 arg1 用服务端返回的 max_payload（TCL 实测 7606）
  • shell:input keyevent KEYCODE_POWER\0 即电视整机待机；5555/WiFi 断开即为关机成功的特征

📦 安装

源码在 ok-dok/tv-manager。APK 直接拉到 Releases 即可：

adb -s <盒子IP>:5555 install -r 电视管家.apk

电视侧 ADB 需要手动打开一次（TCL 国行：设置→关于→本机信息页面一秒内依次按遥控 上→下→左→右）。
